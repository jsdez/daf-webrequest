Lifecycle

constructor()

Initializes the web component through class field initializers. It deliberately does not assign Nintex-bound properties because Nintex can provide them as attributes after construction.

  • Starts with default private execution, debug, and submission state.
  • Hands lifecycle control to Lit and the browser.
The component’s public configuration belongs to Lit @property fields; private fields hold per-instance state only.

✓ Strict success

Transport succeeds and the response classifier returns success. The plugin sets hasSuccessfulCall, emits the result, then can submit the form.

! Warning

The response is classified as warning. A result is emitted, but it is not a strict success and does not start post-success submission.

× Error / blocked

Validation failure, cooldown, invalid JSON, OAuth failure, timeout, or failed transport stops or publishes an error without a native success submission.

↻ Reconfiguration

Changing any request-defining property clears the prior output and emits a pending value so form rules never act on stale API data.
